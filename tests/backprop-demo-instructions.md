Use this small, explicitly simplified network throughout:

z = w*x + b; a = max(0,z); prediction = v*a + c; loss = 0.5*(prediction-target)^2.
The input is fixed at x=2 and the target at 1. Start with w=0.5, b=-0.5, v=1.5, c=0, learning rate=0.05. This gives z=0.5, a=0.5, prediction=0.75, loss=0.03125. All derivatives must use the same pre-update parameters. The gradients are dw=-0.75, db=-0.375, dv=-0.125, dc=-0.25. ReLU has derivative 1 for z>0 and 0 for z<0; use the standard zero derivative convention at z=0 and say this explicitly in optional detail. Inactive ReLU blocks the hidden path, but the output bias c can still learn. Do not imply the whole network has no gradient.

Publish exactly these three rubric criteria (specific hints and misconceptionHint are welcome):

- id chain, label Chain rule. Description: The learner says a loss derivative arriving from downstream is multiplied by each operation's local derivative to obtain the parameter's gradient; for this example dw=(prediction-target)*v*ReLU'(z)*x. Equivalent plain-language explanations count. Sending the same unchanged gradient to every weight is a contradiction. Hint: Follow the small change in w through each operation to the loss.
- id order, label Reverse order. Description: A forward pass first computes/stores values. Backprop then computes derivatives from the loss toward earlier operations in reverse dependency order. Weight updates occur only after gradients have been computed; backprop does not send predictions backward. Hint: Which values must exist before the derivative of each operation can be computed?
- id gate, label Inactive ReLU. Description: For z<0 the local ReLU derivative is zero, so dw, db, and dv through this hidden path are zero. The separate output bias c can still have a nonzero gradient. Claiming an inactive ReLU has derivative one or that every parameter must stop learning is a contradiction. Hint: Separate the hidden path from the output bias.
